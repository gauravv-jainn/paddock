## Worked Examples

1. "if the withdrawn horse was the evens favourite at the time it was
   withdrawn, there would be a R4 deduction of 45p for every pound won"

2. "if the horse was less fancied at odds of 5/1 the R4 deduction would only be
   15p for every pound won"

3. Multiple withdrawals: "if a horse at 7/4 and a horse at 4/1 were withdrawn.
   The R4 deduction would be 35p + 20p = 55p"

NOTES

1. ROW 15 IS OUT OF SEQUENCE. This source publishes "16/15 - 4/1" for the 20p
   band. 16/15 is 1.067 fractional (2.067 decimal), which sits inside the
   45p/40p region and BELOW the 25p band immediately above it (12/5 = 2.4).
   A band table cannot run 12/5 -> 16/15 -> 9/2. It is a typo.

   Four other sources publish "16/5" (3.2 fractional) at this row, which is in
   sequence. One publishes "100/30" (3.333), also in sequence.

   Inserting a '1' into "16/5" produces "16/15" exactly. The most economical
   explanation is that this is a typo FOR 16/5, not for 100/30.
   See tests/consensus/ for the row-by-row tally.

2. Worked example 1 is the ONLY third-party computed number found for row 10,
   the evens band — the row docs/08 D19 marks HIGHEST RISK and which no golden
   vector pins. It states 45p, agreeing with the six-source table and against
   both the old docs/05 value (50p) and the 55p reading cited by docs/09 §3.3.

3. Worked example 3 states deductions, not returns, so it pins bands 12 (35p)
   and 15 (20p) as evidence but is not usable as a golden vector.
